# overheated-programming-2627
Welcome to the Github Repository for Sato Academy's Overheated Programming Club!

Here you will work on practice code and projects. 

There are dedicated folders for advanced cohort, beginner cohort, officers, and students.
Your work will be done in a personal folder, so please don't grief other people's files :)

If you have not done so already, look to the left of the screen to see the "Explorer" panel. 
Here, you can see all of the files and folders located in the repository.
Let's create your personal folder.

Go in to the "Students" folder which should "drop down", and press  "New Folder..." which appears 
in the top right of the "Explorer" panel. Then name your folder using the following format:

firstname-lastname

This is in all lowercase, with no spaces!

NAMING CONVENTIONS

When creating file names and folder names, try not to use spaces! You will learn later that this
this makes accessing them in your code a pain.

Try to separate words with underscores: _ or dashes: -

really-cool-program.py
hello_world.py
